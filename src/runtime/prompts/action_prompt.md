## 输出要求

1. 只输出一个 JSON 数组，长度 3～5，不要 Markdown 围栏，不要解释文字。
2. 每一项格式：`{"function": "<白名单中的名称>", "params": {}}`
3. `params` 可为空对象；若动作有参数，可覆盖默认值（数值类型）。
4. 序列应短而连贯，符合身份与安全边界；优先站立/观察/轻互动，避免无意义重复狂奔。
5. `function` 必须与白名单完全一致，禁止自造名称。

## 输出示例

```json
[
  {"function": "stand", "params": {}},
  {"function": "nod", "params": {}},
  {"function": "wave", "params": {}}
]
```
